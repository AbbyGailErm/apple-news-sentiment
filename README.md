# Apple News Sentiment Analysis - Interim Submission

## Project Overview
This project analyzes financial news headlines to explore their relationship with Apple (AAPL) stock price movements. The goal is to understand how sentiment in news articles may influence stock performance and prepare insights for predictive analytics.

## Interim Submission Scope
For the interim submission, the following tasks have been completed:

1. **Exploratory Data Analysis (EDA):**
   - Loaded Apple stock data (`AAPL.csv`) and financial news data (`financial_news.csv`).
   - Descriptive statistics:
     - Headline length statistics
     - Count of articles per publisher
     - Trends of article publication over time
   - Visualization:
     - Daily number of articles
     - Word cloud of headline keywords
   - Sentiment Analysis:
     - Computed headline polarity using `TextBlob`
     - Visualized average daily sentiment trends
   - Stock Price Overview:
     - Plotted Apple daily closing prices

2. **Data Merging:**
   - Combined daily average news sentiment with Apple stock prices for correlation analysis.
